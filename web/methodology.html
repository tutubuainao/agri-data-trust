评分规则说明

评分标准与实现原理

本系统输出可信度评分和可疑风险，不做“数据一定为假”的判断。当前版本采用“默认核心指标 + 可选增强指标”的结构，优先保证可运行、可解释、可复核。

评分标准

总分范围为 0-100。分数越高，说明当前规则下越接近可解释的自然采集数据；分数越低，说明可疑信号越集中，需要结合采集设备、业务记录和现场环境复核。

总分风险等级含义
70-100低风险未发现明显高风险模式，仍建议结合业务背景复核。
50-69.99中风险存在若干可疑模式，需要查看采集记录、设备日志和数据处理流程。
0-49.99高风险多个指标同时异常，建议优先复核数据来源、采集链路和人工处理痕迹。
总分公式

S = Σ(Wi × Si)

其中 S_i 是本次启用的第 i 个指标子评分，W_i 是该指标在当前场景下的归一化权重。只对用户实际选择的指标求和，所有启用指标权重之和为 100%。

默认核心：S = W采样S采样 + W平滑S平滑 + W数字S数字 + W异常S异常 + W物理S物理

可选指标加入后，权重如何分配

系统不是给每个指标写死一个固定百分比，而是先按规则场景给每个指标一个“相对权重系数” R_i。用户没有开启自定义时，只选择 5 个默认核心指标；用户开启自定义后，只选择用户勾选的指标。最终权重按下面公式重新归一化：

权重归一化公式

Wi = Ri / ΣRj

其中 j 只遍历本次实际启用的指标。未勾选的可选指标不参与求和，也不会影响总分。若用户自定义时取消某个核心指标，该核心指标同样不进入总分。

必要指标与可选指标

为了避免“所有数据都被迫跑全部指标”，系统默认只启用 5 个最关键、适用面最广的核心指标。时序自然性、传感器漂移、变化点、多变量相关性和机器学习异常识别保留为可选增强指标：只有当数据形态匹配时再开启。

规则场景与默认核心权重

规则场景影响两件事：第一，物理范围与单位异常检测会按场景匹配不同字段规则；第二，总分汇总时会使用不同指标相对权重。若用户自定义指标，系统会只在已选择指标之间重新归一化权重。各指标子评分的计算公式不随场景改变。

文件粗筛与防呆处理

列类型处理

时间列用于排序，不参与数值列评分，但会进入采样完整性检测。数值可解析率不低于 70%、有效唯一值不少于 3 的非时间列进入数值类检测。文本列、分类列、空列、常量列会在粗筛表说明跳过原因。

缺失值处理

系统不改写原始数据，也不会把缺失值填回用户文件。数值列通过 pandas.to_numeric(errors="coerce") 清洗，不可解析内容转为缺失；单变量指标使用 dropna() 后的有效序列。机器学习指标为了形成模型矩阵，会在模型内部临时用中位数填补缺失特征，但该操作只用于计算，不改变原始数据和数据预览。

文件格式只接受 CSV、XLSX、XLS。其他格式会直接拒绝，避免把图片、压缩包或无关文件送入分析流程。
空文件如果文件为空、没有表头或没有数据行，系统会给出明确提示，不进入评分。
不可解析列一列中大部分值无法转成数字时，会被视为文本或分类字段，只在粗筛表展示，不进入数值检测。
常量列如果某列所有有效值都一样，无法计算自然波动、异常点和相关结构，会被标记为常量列并跳过。
样本过少有效数值太少时，ACF、IsolationForest 等统计结果不稳定，该列会降级处理或跳过相关指标。
缺失过多缺失率会展示在粗筛表中。当前版本不自动填补，是为了避免系统凭空制造看似正常的数据。

核心与可选检测指标如何计算

每个合格数值列只会执行本次启用的数值类检测；采样完整性、物理规则和机器学习异常识别按整个文件计算；多变量相关性只有在用户选择后才会在所有合格数值列之间计算。子评分会先汇总，再进入总分公式。

指标之间有联系，但用途不同：平滑度关注“过于机械平顺”，时间序列自然性关注“自相关和趋势结构”；异常点分布关注点级异常，变化点检测关注阶段性结构突变；机器学习异常识别关注多变量样本是否被多个模型共同判为异常。因此它们不全部默认启用，而是按数据类型选择。

机器学习与其他指标的边界

机器学习异常识别和部分统计指标存在交集，但不直接矛盾。它是“多变量行级辅助指标”，不替代默认核心指标，也不把同一个风险解释为确定结论。若用户同时开启多个相关指标，结果页会通过权重归一化降低单一指标对总分的影响。

对比指标是否有交集主要区别解读方式
异常点分布有异常点分布是单列点级检测，机器学习是多列组合后的行级检测。两者同时异常时，说明单列离群和多变量组合异常同时存在；不应简单当成两份完全独立证据。
多变量相关性有少量交集相关性检测看变量两两之间是否过强同步，机器学习看整行样本是否偏离整体多变量分布。相关性适合发现复制列、线性推导列；机器学习适合发现“单列不离群但组合不合理”的样本。
时间序列自然性基本不重复时序自然性使用样本顺序和 ACF，机器学习默认不使用时间顺序。连续传感器数据可同时开启；一个看时间结构，一个看多变量样本分布。
变化点/传感器漂移基本不重复变化点和漂移看阶段变化或长期基线迁移，机器学习看单行样本是否异常。如果机器学习异常集中在某一段，再结合变化点或漂移复核采集条件变化。
小数位/数字规律不重复数字规律看尾数、小数位、固定刻度和重复值，机器学习不分析数字书写习惯。数字规律更适合发现人工录入整齐性；机器学习更适合发现多变量组合异常。
1. 平滑度检测

目标是识别“变化过于机械、过于平顺”的序列。真实农业传感器通常会受到天气、设备噪声、采样误差和田间环境影响，不应长期呈现完全等步长变化。

  • 一阶差分：d_t = x_t - x_{t-1}，观察相邻采样的变化幅度。
  • 二阶差分：a_t = d_t - d_{t-1}，观察变化本身是否也过于稳定。
  • 滚动方差：对窗口内数据计算 Var(x_{t-w:t})，若长期接近 0，说明波动不足。
  • 变化率稳定性：r_t = d_t / (|x_{t-1}| + epsilon)，若标准差极小，提示机械生成风险。
简化扣分公式

S平滑 = max(0, 100 - Pdiff - Pcv - Psecond - Proll - Prate)

当前版本使用连续扣分：每个 P 都有一个风险起点和一个极端点，刚超过风险起点时只扣少量分，越接近极端点扣分越多，到极端点才扣满。单列得分取 0-100，多个数值列取平均。

Pdiff
一阶差分幅度扣分。计算 Rdiff = mean(|d_t|) / (max(x)-min(x))。当 Rdiff >= 0.025 时扣 0；当 Rdiff 从 0.025 降到 0 时，扣分从 0 连续增加到 28，公式为 28 × (0.025 - Rdiff) / 0.025。
Pcv
差分变异系数扣分。计算 CVdiff = std(d_t) / (|mean(d_t)| + epsilon)。当 CVdiff >= 0.35 时扣 0；当它从 0.35 降到 0 时，扣分从 0 连续增加到 24。
Psecond
二阶差分扣分。计算 a_t = d_t - d_{t-1} 和 Rsecond = std(a_t) / (max(x)-min(x))。当 Rsecond >= 0.001 时扣 0；当它从 0.001 降到 0 时，扣分从 0 连续增加到 24。
Proll
滚动方差扣分。统计低 rolling variance 窗口占比 Rroll。当 Rroll <= 0.45 时扣 0；当它从 0.45 升到 1 时，扣分从 0 连续增加到 16。
Prate
变化率稳定性扣分。计算 r_t = d_t / (|x_{t-1}| + epsilon) 的标准差 Rrate。当 Rrate >= 0.01 时扣 0；当它从 0.01 降到 0 时，扣分从 0 连续增加到 12。
2. 时间序列自然性检测

目标是判断数据是否具备真实采集数据常见的时间相关性，而不是随机拼接或过度拟合出来的序列。

  • 自相关：计算 corr(x_t, x_{t-k})，重点观察 lag 1-10 的相关性。
  • ACF：使用 statsmodels 计算自相关函数，检查相关性是否随滞后阶数合理衰减。
  • 趋势变化：用一阶差分符号变化率判断趋势是否过于单调或过度频繁反转。
  • 周期性线索：观察 ACF 峰值是否显示合理周期，例如温度、湿度常见日周期。
简化扣分公式

S时序 = max(0, 100 - Pacf1 - Psign - Ptrend - Pacf-high)

当前版本使用连续扣分：自相关越接近极端、趋势变化越少、线性趋势越强，扣分越多。接近阈值时只轻微扣分，极端情况才扣满。

Pacf1
一阶自相关扣分。计算 A1 = corr(x_t, x_{t-1})。当 A1 从 0.98 升到 1 时，正相关扣分从 0 连续增加到 22；当 A1 从 -0.2 降到 -1 时，负相关扣分从 0 连续增加到 10。
Psign
趋势方向变化扣分。统计差分正负号变化率 Rsign。当 Rsign >= 0.08 时扣 0；当它从 0.08 降到 0 时，扣分从 0 连续增加到 20。
Ptrend
线性趋势扣分。计算样本序号 t 与数值 x_t 的相关强度 T，同时参考 Rsign。只有在 T > 0.97 且趋势反转偏少时扣分；T 越接近 1、Rsign 越接近 0，扣分越接近 18。
Pacf-high
高阶自相关结构扣分。计算 lag 2 之后 ACF 绝对值最大值 Ahigh。当 Ahigh >= 0.05 时扣 0；当它从 0.05 降到 0 时，扣分从 0 连续增加到 10。
3. 小数位和数字规律检测

目标是识别人工录入或生成数据常见的“数字太整齐”现象。系统会先区分连续传感器数值和计数型调查指标：温度、湿度、残留浓度等连续值不应长期过于整齐；卵块、卵粒数、成虫数等计数型指标天然可以全部为整数。

  • 整数比例：统计 x mod 1 = 0 的比例。
  • 小数位分布：统计 0 位、1 位、2 位等小数精度是否异常集中。
  • 末位数字分布：统计最后一位有效数字 0-9 的频率，检测是否大量集中在 0、5 或固定尾数。
  • 重复值比例：统计众数占比和连续重复长度。
  • 固定步长：观察相邻差分是否频繁落在同一个值。
简化扣分公式

S数字 = max(0, 100 - Pint - Pdecimal - Ptail - Pround - Pdup)

当前版本使用连续扣分：数字规律越集中，扣分越多；刚超过阈值时只是轻微风险，接近 100% 集中时才扣满。若字段名显示为计数型整数列，例如卵块、卵粒数、幼虫数、成虫数、株数、出蜂数，且数值为非负整数，则整数比例、小数位一致和 0.05 倍数不扣分。

Pint
整数比例扣分。统计整数比例 Rint。当 Rint <= 0.75 时扣 0；当它从 0.75 升到 1 时，扣分从 0 连续增加到 24。
Pdecimal
小数位集中扣分。统计最常见小数位占比 Rdecimal。当 Rdecimal <= 0.90 时扣 0；当它从 0.90 升到 1 时，扣分从 0 连续增加到 20。
Ptail
末位数字集中扣分。统计最后一位有效数字的最常见占比 Rtail。连续型字段中，当 Rtail <= 0.35 时扣 0；当它从 0.35 升到 1 时，扣分从 0 连续增加到 18。计数型字段阈值放宽为 0.65 到 0.95，最多扣 8 分。
Pround
固定刻度扣分。统计落在 0.05 整数倍上的比例 Rround。当 Rround <= 0.80 时扣 0；当它从 0.80 升到 1 时，扣分从 0 连续增加到 16。
Pdup
重复值扣分。计算重复比例 Rdup = 1 - 唯一值数量 / 有效样本数。当 Rdup <= 0.45 时扣 0；当它从 0.45 升到 1 时，扣分从 0 连续增加到 12。
4. 异常点分布检测

目标是判断序列中是否存在合理的自然波动。农业原始采集数据完全没有异常点并不一定更可信，可能意味着被过度清洗或生成得过于完美。

  • z-score：z = (x - mean) / std，通常关注 |z| > 3 的点。
  • IQR：计算 Q1 - 1.5IQR 和 Q3 + 1.5IQR 外的点。
  • IsolationForest：使用 scikit-learn 对单列数值进行无监督异常检测。
  • 异常比例：统计异常点占比是否过低或过高。
简化扣分公式

S异常 = max(0, 100 - Pnone - Pmany - Pfew - Pcv)

当前版本使用连续扣分：异常点太少或太多都会增加风险，越接近极端情况扣分越多。“没有异常”不会被当成更好，而是作为可能过度清洗的线索。

Pnone
自然异常不足扣分。计算 z-score 和 IQR 检出的最大异常比例 Rnatural。当 Rnatural >= 0.02 时扣 0；当它从 0.02 降到 0 时，扣分从 0 连续增加到 28。
Pmany
异常过多扣分。综合 z-score、IQR 和 IsolationForest 的最大异常比例 Rout。当 Rout <= 0.25 时扣 0；当它从 0.25 升到 1 时，扣分从 0 连续增加到 24。
Pfew
异常过少扣分。样本量足够时，如果综合异常比例 Rout 低于 0.02，会从 0.02 到 0 连续扣 0-10 分，用于提示可能过度清洗。
Pcv
整体变异不足扣分。计算 CV = std(x) / (|mean(x)| + epsilon)。当 CV >= 0.005 时扣 0；当它从 0.005 降到 0 时，扣分从 0 连续增加到 16。
5. 传感器漂移检测

目标是识别同一传感器或同一指标在长期采集中是否出现基线缓慢偏移。它不会直接说明数据造假，也可能对应真实农情变化、传感器老化、校准前后差异或采样环境变化，因此结果只作为复核线索。

  • 前后窗口均值偏移：取序列前后两个窗口，比较 mean(head) 与 mean(tail) 的差距。
  • 滚动均值斜率：对滚动均值序列做一元线性拟合，观察基线是否持续单向移动。
  • CUSUM 累积偏差：计算中心化序列的累积和，用于识别阶段性基线迁移。
  • 前后窗口方差变化：比较前后窗口标准差，提示设备状态或采集条件是否改变。
  • 变化方向单一性：统计相邻差分方向是否长期偏向同一方向。
简化扣分公式

S漂移 = max(0, 100 - Pmean - Pslope - Pcusum - Pvar - Pdir)

当前版本使用传统统计方法和连续扣分。先设 scale = max(max(x)-min(x), std(x), epsilon)，用于把不同量纲的温度、湿度、产量等指标转成可比较的相对强度。每个扣分项从风险起点开始逐渐增加，达到极端点才扣满。

Pmean
前后窗口均值偏移扣分。计算 Rmean = |mean(tail) - mean(head)| / scale。当 Rmean <= 0.35 时扣 0；当它从 0.35 升到 1 时，扣分从 0 连续增加到 30。
Pslope
滚动均值斜率扣分。先计算滚动均值 m_t，再用 m_t = a + bt 拟合斜率 b，得到 Rslope = |b| × (n-1) / scale。当 Rslope <= 0.30 时扣 0；当它从 0.30 升到 1 时，扣分从 0 连续增加到 25。
Pcusum
CUSUM 累积偏差扣分。计算 c_t = sum(x_i - mean(x))，再取 Rcusum = (max(c_t)-min(c_t)) / (std(x) × n)。当 Rcusum <= 0.18 时扣 0；当它从 0.18 升到 0.45 时，扣分从 0 连续增加到 20。
Pvar
前后窗口方差变化扣分。计算 Rvar = |std(tail)-std(head)| / std(x)。当 Rvar <= 0.60 时扣 0；当它从 0.60 升到 1.50 时，扣分从 0 连续增加到 15。
Pdir
变化方向单一扣分。计算非零差分方向的平均绝对值 Rdir = |mean(sign(d_t))|。当 Rdir <= 0.80 时扣 0；当它从 0.80 升到 1 时，扣分从 0 连续增加到 10。
6. 变化点检测

目标是识别序列是否存在阶段性突变，例如设备校准、换传感器、采集环境切换或人工分段处理。它和传感器漂移不同：漂移关注缓慢偏移，变化点关注某个阶段前后的结构差异。

  • 滑动窗口均值差异：比较变化点前后两个窗口的均值差异。
  • CUSUM：观察中心化累积和是否出现明显偏移。
  • Page-Hinkley：用在线统计量捕捉均值突变信号。
简化扣分公式

S变点 = max(0, 100 - Pwin - Pcusum - Pph)

Pwin
滑动窗口均值差异扣分。计算 Rwin = max(|mean(right)-mean(left)|) / scale。当 Rwin <= 0.25 时扣 0；从 0.25 到 0.80 连续扣 0-35 分。
Pcusum
CUSUM 扣分。计算 Rcusum = (max(c_t)-min(c_t)) / (std(x) × n)。当 Rcusum <= 0.18 时扣 0；从 0.18 到 0.45 连续扣 0-25 分。
Pph
Page-Hinkley 扣分。计算在线累积偏差统计量并按 std(x) × sqrt(n) 标准化；当标准化值从 2.5 升到 5.0 时，扣分从 0 连续增加到 25。
7. 采样完整性检测

目标是复核原始采集链路是否完整，重点关注时间间隔、重复时间戳、连续缺测和 Excel 工作表结构。没有时间列时不会直接判定高风险，但会提示无法复核采样完整性。

  • 时间间隔 CV：CV = std(Δt) / mean(Δt)，衡量采样频率是否稳定。
  • 重复时间戳比例：统计重复时间点占比。
  • 断点数量：若某段间隔超过中位间隔的 3 倍，记为采样断点。
  • 最长连续缺测：按中位采样间隔估计 gap 中缺少的采样槽数量。
  • 工作表结构异常：多个工作表合并时，比较各工作表的有效字段集合差异。
简化扣分公式

S采样 = max(0, 100 - Pdup - Pcv - Pgap - Pmiss - Ptable)

Pdup
重复时间戳扣分。重复比例从 1% 到 10% 连续扣 0-22 分。
Pcv
时间间隔波动扣分。时间间隔 CV 从 0.35 到 1.20 连续扣 0-22 分。
Pgap
采样断点扣分。每个明显断点扣 4 分，最多扣 18 分。
Pmiss
最长连续缺测扣分。估计连续缺测槽从 2 到 12 个连续扣 0-14 分。
Ptable
工作表结构扣分。字段集合差异比例从 0.20 到 0.80 连续扣 0-14 分；空工作表会额外轻微扣分。
8. 物理范围与单位异常检测

目标是用农业常识做防呆复核。用户可选择“温室数据 / 虫害调查 / 产量调查 / 农残检测”等场景，系统按字段名称匹配规则，并在总分公式中切换对应场景权重。该指标只提示单位、量纲或录入风险，不替代法规限量或专家判定。

  • 温室数据：温度、湿度、土壤水分、光照、CO2、pH、EC。
  • 虫害调查：卵量、幼虫、成虫、诱捕量、寄生率。
  • 产量调查：产量、面积、株高、重量等非负农艺指标。
  • 农残检测：农药残留、检出限、浓度、含量等非负指标。
简化扣分公式

S物理 = max(0, 100 - Phard - Psoft - Punit - Pcover)

Phard
硬范围扣分。超出物理硬范围的比例从 0 到 15% 连续扣 0-28 分，例如湿度小于 0 或大于 100。
Psoft
经验范围扣分。超出常见经验范围的比例从 2% 到 30% 连续扣 0-16 分。
Punit
疑似单位异常扣分。例如湿度字段全部落在 0-1，可能是比例而不是百分数，会轻微扣分并提示复核。
Pcover
规则覆盖扣分。若可匹配到物理规则的字段少于 25%，提示选择更合适场景或规范字段名。
9. 多变量相关性检测

目标是发现变量之间过强相关、完美线性关系或人为复制列。真实农业变量可能相关，但通常不会长期保持完全线性。

  • Pearson 相关：检测线性关系，计算 corr(X, Y)。
  • Spearman 相关：检测单调关系，适合非线性但排序关系很强的变量。
  • 相关矩阵：对所有合格数值列两两计算，并生成热力图。
  • 高相关阈值：若多个变量绝对相关系数接近 1，需要提示人工复核。
简化扣分公式

S相关 = max(0, 100 - Pperfect - Phigh - Pavg)

当前版本使用连续扣分：相关系数越接近 1 或 -1，扣分越多；只有近乎完美相关时才扣满。

Pperfect
近乎完美相关扣分。计算所有变量对的 Pearson/Spearman 最大绝对相关 Cmax。当 Cmax <= 0.999 时扣 0；当它从 0.999 升到 1 时，扣分从 0 连续增加到 35。
Phigh
过强相关扣分。仍使用 Cmax。当 Cmax <= 0.99 时扣 0；当它从 0.99 升到 0.999 时，扣分从 0 连续增加到 14。
Pavg
整体同步扣分。计算全部变量对 Pearson 绝对值平均数 Cavg。变量对不少于 3 时，若 Cavg 从 0.96 升到 1，扣分从 0 连续增加到 18。
10. 机器学习异常识别

目标是在用户主动开启时，用传统机器学习模型补充统计规则。当前版本不训练“真/假分类器”，因为多数农业场景暂时缺少可靠标注；系统采用无监督异常检测，只判断多模型是否共同发现多变量异常样本。

  • 特征准备：只使用通过粗筛的数值列，缺失值用中位数填充，再用 RobustScaler 做稳健缩放。
  • 模型集成：同时运行 IsolationForest、LocalOutlierFactor 和 OneClassSVM；为保证线上响应稳定，最多抽样 800 行进入模型计算。
  • 模型共识：如果至少约三分之二模型把同一行判为异常，该行记为“模型共识异常”。
  • 适用条件：至少 20 行、至少 2 个有效数值特征；单列数据仍建议主要查看异常点分布。
简化扣分公式

S机器 = max(0, 100 - Pconsensus - Pmodel - Pdisagree - Pspread - Psmall)

机器学习分数只作为可选辅助指标。它不会覆盖传统统计指标，也不会给出“数据为假”的结论；当样本量不足或特征不足时，系统会降级提示。

Pconsensus
模型共识异常扣分。计算 Rconsensus，即被至少三分之二模型共同判为异常的样本比例。当 Rconsensus <= 0.08 时扣 0；从 0.08 升到 0.25 连续扣 0-35 分。
Pmodel
单模型异常比例过高扣分。计算三个模型中最高异常比例 Rmax。当 Rmax <= 0.20 时扣 0；从 0.20 升到 0.45 连续扣 0-18 分。
Pdisagree
模型分歧扣分。计算 Rdisagree，即模型之间没有形成一致判断的样本比例。当 Rdisagree <= 0.35 时扣 0；从 0.35 升到 0.75 连续扣 0-12 分。
Pspread
异常比例跨度扣分。计算不同模型异常比例的最大差值 Rspread。当 Rspread <= 0.12 时扣 0；从 0.12 升到 0.35 连续扣 0-10 分。
Psmall
样本量不足扣分。机器学习有效样本数从 50 降到 20 时，连续扣 0-10 分；少于 20 行时不做正式模型判断。

跨传感器一致性同一地块、相邻设备或相似变量之间应有一定一致性，可检测单个设备故障或局部异常。

为什么第一版不直接加入复杂深度学习

农业数据场景常常缺少高质量标注，且用户需要知道“为什么可疑”。因此当前版本把传统机器学习作为可选增强指标，不作为默认核心指标；后续如果有稳定历史数据和人工标注，再加入 RandomForest、XGBoost/LightGBM 或深度时序异常检测模型。
